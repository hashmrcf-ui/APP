# عالم بومي — Boomi World

تطبيق تعليمي للأطفال (3–7 سنوات)، عربي أولاً مع الإنجليزية.

## الرسوم

- `design/palette.json` — لوحة الألوان (مصدر واحد لكل الرسوم).
- `design/build.mjs` — يرسم كل ملفات SVG بالكود ويبني لوحة الأسلوب.
- `assets/svg/characters/` — بومي بثلاثة تعابير، أجزاؤه منفصلة (`eyes`, `wing-l`, `wing-r`, `face`) للتحريك.
- `assets/svg/items/` — العناصر: تفاحة، نجمة، شمس، غيمة، حرف، رقم.
- `design/style-board.html` — لوحة الأسلوب الأولى (افتحها في المتصفح).
- `design/home-art.mjs` — شخصيات الشاشة الرئيسية (بومي، فنّوك، جملو، روبي، لولو) والبطاقات والأيقونات.
- `design/home.html` — تصميم الشاشة الرئيسية للتطبيق بأسلوب Lingokids.
- `assets/svg/heads/`، `assets/svg/badges/`، `assets/svg/cards/` — رؤوس الشخصيات ودوائرها وبطاقات الدروس.

لإعادة البناء بعد تعديل الألوان أو الأشكال:

```sh
node design/build.mjs
```

## القرارات

| | |
|---|---|
| التقنية | Flutter + Rive (حركة) + Flame (ألعاب) |
| العمر | 3–7 سنوات بمستويين |
| اللغة | عربي أولاً + English |
| الرسوم | SVG → Rive |

ملاحظة: ملفات الحرف والرقم تستخدم خط `Baloo Bhaijaan 2`؛ داخل Flutter نحولها لاحقاً إلى مسارات أو نرسم النص بالخط المضمّن في التطبيق.
